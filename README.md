# Информационный центр Управления ветеринарии Ленинградской области

Интерактивный сайт, перевёрстанный по 24 содержательным страницам оригинальной PDF-презентации. Пустая 25-я страница исключена. Заголовки, карточки, схемы, интерфейс AI и навигация реализованы HTML/CSS/JS. Карта, фотографии, логотипы и шесть реальных дашбордов извлечены из исходника; полные изображения страниц используются только в обзоре как миниатюры.

## Просмотр

Публичная версия: https://andreyosikin.github.io/vet-info-center-presentation/

Можно открыть `index.html` прямо с диска — внешних библиотек, шрифтов и сетевых сервисов нет. Для локального сервера: `python -m http.server 8080`, затем http://localhost:8080/.

## Управление

- Стрелки, Page Up / Page Down, пробел, колесо мыши: переход между экранами.
- Home / End: первый / последний экран.
- O: обзор всех 24 экранов. Esc закрывает обзор.
- F: полноэкранный режим; разрешение зависит от браузера.
- Вертикальный свайп прокручивает сайт; горизонтальный переключает экраны.
- `#s14` и аналогичные якоря открывают конкретный экран.
- На экране 24 кнопка воспроизводит десять шагов демонстрационной цепочки. Повторное нажатие останавливает её.

## Визуальная система

Композиция масштабируется целиком в соотношении 16:9 под 1920×1080 и ноутбуки. Светло-голубая среда, природа Ленинградской области, стеклянные карточки и синий акцент сохранены. SVG-потоки, последовательное раскрытие, parallax, подсветка процессов, рисование hero-графика и анимация аналитических панелей работают только на активном экране. Настройка `prefers-reduced-motion` отключает движение.

Основные вырезанные изображения сохранены в lossless WebP из доступных JPEG внутри PDF. Их исходная детализация ограничена PDF, дополнительное увеличение не добавляет деталей. Сжатые миниатюры применяются только в обзоре. Важные изображения предзагружаются; остальные загружаются лениво и декодируются перед соседним экраном.

## Содержание и границы демонстрации

Порядок соответствует PDF: 11 — Ферма → СББЖ → Управление; 14 — аналитика; 18 — 2-ВЕТ; 19 — интеграции; 20–21 — AI; 24 — практическая демонстрация.

Статусы функций, цифры и примеры перенесены из презентации. Сайт не подключён к рабочей базе и не подтверждает текущую готовность представленных функций. 2-ВЕТ обозначен «В работе», интеграции сохраняют статусы исходника, AI для Информационного центра — перспектива. Чат на экране 21 является иллюстрацией. Финансовый сценарий условный.

## Проверка

Проверены все 24 экрана локально, загрузка изображений, отсутствие обрезки карточек, обзор, переходы кнопками, стрелками и колесом. Проверена вёрстка в 1920×1080 и на ноутбуке. Полноэкранная кнопка вызывает штатный API браузера; встроенный браузер может автоматически завершать этот режим. Физический сенсорный экран для проверки свайпа недоступен.
